# Introduction à QML et Qt Quick

> [Revenir au tutoriel Qt 6](../README.md)

QML est un langage déclaratif destiné à décrire des interfaces et leurs comportements. Qt Quick fournit les types visuels
et le moteur qui les affiche. Qt Quick Controls ajoute les contrôles d'interface usuels (boutons, champs de saisie, menus,
etc.).

Pour essayer les exemples, créez un projet Qt Quick dans Qt Creator. Les modules QML employés doivent être installés avec
Qt et déclarés dans le projet CMake. Les exemples utilisent les imports sans numéro de version, convention recommandée
dans les projets Qt 6 récents.

# Savoir utiliser la documentation de Qt

> [Revenir à la page d'installation de Qt 6](README.md)

La documentation officielle est disponible sur [doc.qt.io](https://doc.qt.io/qt-6/). Veillez à consulter la version
correspondant à votre installation ; les pages `dev` et les snapshots décrivent parfois des fonctionnalités en cours
de développement et ne sont pas la référence d'une version publiée.

Pour chercher une classe ou une propriété :

1. Relevez son nom exact dans le code ou le message d'erreur.
2. Recherchez ce nom sur le site Qt ou dans l'aide intégrée à Qt Creator (`F1`).
3. Vérifiez le module requis, la version d'introduction, les plateformes prises en charge, les exemples et les notes
   indiquant qu'une API est obsolète.
4. Pour une erreur de build, lisez aussi la documentation CMake, du compilateur et du kit concernés.

Les pages des modules contiennent des exemples et liens vers les classes. Les guides **Getting Started**, les exemples
installés avec Qt et les notes de version sont utiles pour comprendre un sujet dans son contexte. Pour signaler un
problème reproductible dans Qt lui-même, consultez le [Qt Project Bug Tracker](https://bugreports.qt.io/).

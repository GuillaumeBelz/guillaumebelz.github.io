# Demander de l'aide sur Qt

> [Revenir à la page d'installation de Qt 6](README.md)

Vous pouvez poser une question sur le [forum Qt](https://forum.qt.io/) ou dans une communauté de programmation adaptée.
Avant de publier, cherchez le message d'erreur exact et vérifiez la documentation de la version utilisée.

Pour rendre la question reproductible, indiquez :

- le système et la version de Qt ;
- Qt Creator ou l'outil de construction utilisé ;
- le kit (compilateur, architecture, cible) et la configuration Debug/Release ;
- les étapes exactes, le résultat attendu et le résultat obtenu ;
- le message d'erreur complet et le premier diagnostic pertinent ;
- un petit exemple autonome qui reproduit le problème.

Partagez uniquement le code nécessaire et retirez les clés, jetons, mots de passe, données personnelles et chemins contenant
des informations privées. Si le projet complet est indispensable, utilisez un dépôt accessible aux personnes qui vous
aident et vérifiez le contenu avant de le rendre public.

Rédigez un titre spécifique, expliquez ce que vous avez déjà essayé et restez courtois. Pour un bogue reproductible dans
Qt lui-même, consultez le [Qt Project Bug Tracker](https://bugreports.qt.io/) et vérifiez qu'il ne s'agit pas d'une
configuration ou d'une erreur dans votre application.
